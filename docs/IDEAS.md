# Ideas and Out-of-Scope Backlog

This document captures enhancement ideas, future phase concepts, and non-essential features that fall outside the active milestone scope. In accordance with standing project rules, no bonus features or scope creep may enter active milestone execution.

## Potential Future Ideas (Post Phase 3)
1. Offline PWA caching for confirmed itinerary details when travelling in remote regions with intermittent cellular coverage.
2. Integration with official Indian Indian Railway (IRCTC) or state transport bus schedule links for travel guidance (links only, no data scraping).
3. Community audio pronunciation guides for regional language phrases (e.g., Maithili greetings in Darbhanga/Madhubani, Bhojpuri, Malayalam).
4. Automated PDF generation for guest compliance reporting export for hosts to print physically for local police station records where digital Form C / Form III is submitted manually.
5. Multi-currency price display conversion estimator (read-only advisory rate) once Phase 2 PAYMENTS_ENABLED is switched on.
